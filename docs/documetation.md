# Geometric lib - документация
## Общее описание библиотеки
Geometric lib -**python** библиотека с функциями нахождения площадей и периметров разных геометрических фигур
## Принцип реализации
для каждой фигуры создан свой файл, в котором реализованы функции принадлежащие этой фигуре. Все функции принимает абстрактные числовые параметры (функция примит любой тип который можно умножать, делить и складывать) **и возращают значение в этом же типе**
## Список реализованных фигур
1. круг - circle.py
2. прямоугольник -rectangle.py
3. квадрат - square.py
4. треугольник - triangle.py

---

## Подробное описание функций

### 1. Круг (`circle.py`)

Модуль содержит функции для вычисления площади круга и длины окружности. Для расчетов используется математическая константа $\pi$ из стандартной библиотеки `math`.

#### Математические формулы:
* **Площадь**: $S = \pi r^2$
* **Периметр (длина окружности)**: $P = 2 \pi r$

---

#### `area(r)`
Вычисляет площадь круга по его радиусу.

* **Параметры:**
  * `r` (*int | float*): радиус круга.
* **Возвращаемое значение:**
  * (*float*): площадь круга с радиусом `r`.
* **Пример вызова:**
  ```python
  import circle

  res = circle.area(5)
  print(res)  # 78.53981633974483
---
> [!NOTE]
>perimeter(r)
>Вычисляет длину окружности по её радиусу.
>**Параметры**:
>r (int | float): радиус круга.
>**Возвращаемое значение:**
>(float): длина окружности с радиусом r.
#### Пример вызова:

```python
    import circle

    res = circle.perimeter(5)
    print(res)  # 31.41592653589793
```

## 2. Прямоугольник (`rectangle.py`)

Модуль содержит функции для вычисления площади и периметра прямоугольника.

#### Математические формулы:
* **Площадь**: $S = a \cdot b$
* **Периметр**: $P = 2(a + b)$

---

#### `area(a, b)`
Вычисляет площадь прямоугольника по его сторонам.

* **Параметры:**
  * `a` (*int | float*): длина прямоугольника.
  * `b` (*int | float*): ширина прямоугольника.
* **Возвращаемое значение:**
  * (*int | float*): площадь прямоугольника со сторонами `a` и `b`.
* **Пример вызова:**
  ```python
  import rectangle

  res = rectangle.area(5, 8)
  print(res)  # 40
  ```

---

#### `perimeter(a, b)`
Вычисляет периметр прямоугольника по его сторонам.

* **Параметры:**
  * `a` (*int | float*): длина прямоугольника.
  * `b` (*int | float*): ширина прямоугольника.
* **Возвращаемое значение:**
  * (*int | float*): периметр прямоугольника со сторонами `a` и `b`.
* **Пример вызова:**
  ```python
  import rectangle

  res = rectangle.perimeter(5, 8)
  print(res)  # 26
  ```

---

## 4. Треугольник (`triangle.py`)

Модуль содержит функции для вычисления площади и периметра треугольника.

#### Математические формулы:
* **Площадь**: $S = \frac{a \cdot h}{2}$
* **Периметр**: $P = a + b + c$

---

#### `area(a, h)`
Вычисляет площадь треугольника по основанию и высоте.

* **Параметры:**
  * `a` (*int | float*): основание треугольника.
  * `h` (*int | float*): высота треугольника, опущенная на основание `a`.
* **Возвращаемое значение:**
  * (*int | float*): площадь треугольника с основанием `a` и высотой `h`.
* **Пример вызова:**
  ```python
  import triangle

  res = triangle.area(10, 5)
  print(res)  # 25.0
  ```

---

#### `perimeter(a, b, c)`
Вычисляет периметр треугольника по его сторонам.

* **Параметры:**
  * `a` (*int | float*): первая сторона треугольника.
  * `b` (*int | float*): вторая сторона треугольника.
  * `c` (*int | float*): третья сторона треугольника.
* **Возвращаемое значение:**
  * (*int | float*): периметр треугольника со сторонами `a`, `b`, `c`.
* **Пример вызова:**
  ```python
  import triangle

  res = triangle.perimeter(3, 4, 5)
  print(res)  # 12
  ```






## Пример комплексного использования библиотеки
```python
    import circle
    import rectangle
    import square
    import triangle

    # Круг
    print("Круг S:", circle.area(10))
    print("Круг P:", circle.perimeter(10))

    print("Прямоугольник P:", rectangle.perimeter(5, 8))

    # Квадрат
    print("Квадрат S:", square.area(4))
    print("Квадрат P:", square.perimeter(4))

    # Треугольник
    print("Треугольник S:", triangle.area(10, 5))
    print("Треугольник P:", triangle.perimeter(3, 4, 5))
```
