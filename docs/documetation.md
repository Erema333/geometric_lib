# Geometric lib - документация
## Общее описание библиотеки
Geometric lib -**python** библиотека с функциями нахождения площадей и периметров разных геометрических фигур
## Принцип реализации
для каждой фигуры создан свой файл, в котором реализованы функции принадлежащие этой фигуре. Все функции принимает абстрактные числовые параметры (функция примит любой тип который можно умножать, делить и складывать) **и возращают значение в этом же типе**
## Список реализованных фигур
1. круг - circle.py
2. прямоугольник -rectangle.py
3. квадрат - square.py
4. треугольник - triangle.py

---

## Подробное описание функций

### 1. Круг (`circle.py`)

Модуль содержит функции для вычисления площади круга и длины окружности. Для расчетов используется математическая константа $\pi$ из стандартной библиотеки `math`.

#### Математические формулы:
* **Площадь**: $S = \pi r^2$
* **Периметр (длина окружности)**: $P = 2 \pi r$

---

#### `area(r)`
Вычисляет площадь круга по его радиусу.

* **Параметры:**
  * `r` (*int | float*): радиус круга.
* **Возвращаемое значение:**
  * (*float*): площадь круга с радиусом `r`.
* **Пример вызова:**
  ```python
  import circle

  res = circle.area(5)
  print(res)  # 78.53981633974483
perimeter(r)
Вычисляет длину окружности по её радиусу.
Параметры:
r (int | float): радиус круга.
Возвращаемое значение:
(float): длина окружности с радиусом r.
Пример вызова:
code
Python
import circle

res = circle.perimeter(5)
print(res)  # 31.41592653589793
